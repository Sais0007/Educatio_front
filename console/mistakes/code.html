Remediation Breakdown

Step-by-Step Derivation Walkthrough

1. Consider torque about the instantaneous axis of zero velocity: τ_IAOR = I_IAOR × α.

2. Using the Parallel Axis Theorem: I_contact = I_cm + MR² = (2/5 MR²) + MR² = 7/5 MR².

3. Applied torque about the contact point is F × (R + h). Equating F(R + h) = (7/5 MR²) × (F / M) leads directly to h = 2/5 R.
